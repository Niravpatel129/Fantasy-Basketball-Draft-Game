# Fantasy Basketball Draft Game

## About

Fantasy Basketball Draft Game is a full-stack web application for making basketball predictions and tracking game-related picks. It combines a React client with an Express/Mongoose backend, Google sign-in, scheduled jobs, and application state around prediction workflows.

## Tech stack

- React
- Node.js / Express
- MongoDB / Mongoose
- Google Sign-In
- node-schedule
- Axios

## Development

This is a legacy project and declares an older Node.js runtime. Use a compatible Node version when installing dependencies.

Install server dependencies:

```bash
npm install
```

Install client dependencies:

```bash
cd client
npm install
cd ..
```

Run both client and server in development:

```bash
npm run dev
```

Run the server:

```bash
npm start
```
